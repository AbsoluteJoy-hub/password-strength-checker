# Personal Cybersecurity Audit

## Project Overview

This project is a beginner-level cybersecurity audit designed to identify
common security risks and recommend practical ways to improve personal
digital security.

## Areas Reviewed

### 1. Password Security

**Risk:** Using weak, reused, or predictable passwords can increase the
risk of unauthorized account access.

**Recommendation:**
- Use unique passwords for important accounts.
- Use long and difficult-to-guess passwords.
- Use a reputable password manager where appropriate.

### 2. Multi-Factor Authentication

**Risk:** Accounts protected only by passwords have less protection if a
password is compromised.

**Recommendation:**
Enable multi-factor authentication on important accounts whenever it is
available.

### 3. Software Updates

**Risk:** Outdated software may contain known security vulnerabilities.

**Recommendation:**
Keep the operating system, applications, browsers, and security software
updated.

### 4. Phishing Awareness

**Risk:** Phishing messages can trick users into revealing credentials or
other sensitive information.

**Recommendation:**
Check links and senders carefully and avoid entering credentials through
suspicious links or messages.

### 5. Device Security

**Risk:** An unsecured device can expose personal information if it is
lost or accessed by someone else.

**Recommendation:**
Use a screen lock, keep the device updated, and avoid installing
applications from untrusted sources.

## Key Findings

The audit demonstrates that cybersecurity is not only about advanced
hacking techniques. Good security also depends on strong passwords,
account protection, software updates, phishing awareness, and secure
device practices.
