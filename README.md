# Password Strength Checker

A beginner cybersecurity project built with Python to evaluate password strength and generate random passwords.

## Project Overview

This project demonstrates basic cybersecurity concepts through a simple command-line password security tool.

It evaluates passwords based on:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It also provides suggestions for improving weak passwords.

## Features

### Password Strength Checker

The program classifies passwords as:

- Weak
- Medium
- Strong
- Very Strong

It also provides recommendations when security requirements are missing.

### Password Generator

The program can generate a random 16-character password containing:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

## Technologies Used

- Python
- Regular Expressions (`re`)
- `secrets` module
- `string` module
